## 四、✅ 晶振与板载资源（已按正确原理图 LXB407VG-P1 核实，2026-09-29）

原理图：`F:\于RTOS的多功能工业网关81059938718275\【4】原理图尺寸图\LXB407VG-P1原理图.pdf`；商家标准库例程在 `1781059938718275\【1】参考例程\标准库\`（LED/按键/串口/RTC/1.54寸屏/3.5寸屏，引脚已与例程 led.h 交叉验证一致）

- **主控 STM32F407VGT6**（1MB Flash / 192KB RAM），与开发计划一致
- **HSE = 8MHz（X1）**：已应用——Define 加了 `HSE_VALUE=8000000`，`PLL_M` 已改 8，系统时钟 168MHz
- **板载 32.768kHz RTC 晶振 + CR1220 纽扣电池**（VBAT）：内部 RTC 可掉电走时，**M6 DS1307 模块可以省掉**（省一条 I2C，精度还更好）
- **用户 LED = PC0**（LED2 蓝光，低电平点亮）；LED1 红光为电源指示灯常亮——main.c 已按此配置并与商家 led.h 交叉验证
- **用户按键 = PC1**（KEY）；**BOOT0 按键**：按住 BOOT0 再复位可进 ISP 串口下载模式
- **板上没有 W25QXX、没有 TF 卡座** → **M7 W25Q64 模块、M16 SD 模块照计划正常使用**
- **SPI 液晶座（FPC 8P，接 1.54寸屏）**：SPI3 PB3(SCK)/PB5(MOSI)，CS=PA15，DC=PD13，BL=PD12，RST 由板上 RC 电路硬件复位（不占 GPIO）——与计划"TFT 接 SPI3"一致，DC/BL 引脚按此修正（原计划 PC7/PC8/PC9 作废）
- **FSMC 液晶座（FPC 32P，3.5寸屏选配）**：8080 并口 + 电阻触摸**占用 SPI1（PA5/PA6/PA7）+ PB8/PB9**——**与阶段5 W5500（SPI1）冲突：接 W5500 时不要插 3.5寸触摸屏**
- **USB TypeC** 直连 PA11/PA12（支持 USB DFU 下载，可玩 USB 应用）
- IO 引出：2×21P 排针两排（PA13/PA14、PC14/PC15、晶振脚不引出）
- 供电：推荐 5V 进 TypeC 或 5V 引脚，板载 RY3420 DCDC 降压 3.3V

## 五、常见问题

| 现象 | 原因/处理 |
|---|---|
| 串口乱码 | 晶振不匹配（见第四节）或波特率没设 115200 |
| LED 不闪 | 检查下载是否成功、BOOT0 是否接 GND |
| 下载器识别不到 | 装 ST-Link 驱动；SWD 线序 SWDIO=PA13, SWCLK=PA14 |
| 想加自己的模块 | 建议在工程里加 Hardware 组，放 xxx.c/xxx.h，头文件加进 Include Paths |
| 屏幕背光亮但白屏/黑屏 | 检查 FPC 排线方向、屏幕型号是否 ST7789 240x240；SPI3 已按板载座固定（PB3/PB5+PA15/PD13/PD12），一般不用动 |
| LCD_DisplayDecimals 显示乱码 | MicroLIB 的 sprintf 不支持 %f——要显示小数需关 MicroLIB（Options→Target）或自行实现浮点转字符串 |
