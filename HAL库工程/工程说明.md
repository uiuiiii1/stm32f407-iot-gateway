## 一、与标准库的差异（实现方式，功能一致）
- **延时**：HAL `delay.c` 调度器前用 `HAL_GetTick`（依赖 SysTick 中断）→ 必须 `__enable_irq()`（`Core\Src\main.c` USER CODE 区）+ `VECT_TAB_OFFSET=0x8000`（`system_stm32f4xx.c`）。标准库是 NOP 忙等，不需要（见踩坑 #38）。
- **开机签名**：HAL 打 `LCD: 0x29 ...`，标准库没有——多固件共板先核对签名。
- **.ioc**：CubeMX 工程，勿在图形界面改外设/引脚；自定义代码放 USER CODE 区；重生成会恢复 it.c 的 SVC/PendSV/SysTick 空函数（与 FreeRTOS port 冲突 L6200E），届时删生成版。

## 二、已含功能（与标准库对齐）
AT24C64 软I2C + 双槽书签 / datalog 断网缓存+补传（AT24C64 书签、30s 限流、`DL_BookmarkCommit`）/ SNTP / MQTT 订阅+下行 / OTA 下载器+确认+NotifyAlive / 应用搬家 0x08008000 / 共享 bootloader（A2 计数 + A3 Slot B 回滚）。

## 九、阶段11 SD 卡归档升级记录（2026-10-07，已上板验收，SPL+HAL 双工程）

- **硬件**：MicroSD 模块（带 AMS1117 稳压，VCC 必须接 5V）+ 8GB 卡（**FAT32 格式**，exFAT 不支持）；**软件 SPI 专用总线**：CS=PC6 / SCK=PC7 / MISO=PC8 / MOSI=PC9（GPIO 位拍，模式0）——不与 W25Q64 共享 SPI2（原方案因 SD 模块 MISO 缓冲器常使能抢线废弃，踩坑 #40）；Init 期 400kHz、读写 2MHz（DWT 半位延时）
- **FatFS R0.12c**（本机 STM32Cube 仓库提取）：工程 `FatFs/`；ffconf：LFN 关/CP1/TINY/单写者（LOCK、REENTRANT 全 0）/**_USE_MKFS 0（板端格式化已禁用——不可分割长调用实测复位循环）**；`Hardware/diskio_sd.c` 桥接；get_fattime 用 RTC（无效回 2026-01-01）
- **挂载前介质预检（app.c，勿删）**：裸读扇区 0，EXFAT 魔数/无 FAT 类型分区/无 FAT 签名 → 拒绝挂载（R0.12c check_fs 的 JumpBoot 规则会误判，踩坑 #41）；**f_getfree 全项目禁用**（FSINFO 无效时全表扫描 ~75s 远超 IWDG）
- **归档模块 `Hardware/sdlog.c/h`**：按天 `YYYYMMDD.CSV`（8.3 短名），行格式 `unix,温度x10,湿度x10
`；文件常开+每 10 条 f_sync+跨天换文件；RTC 无效期写 NODATE.CSV；失败降级+60s 重探测；**只在 STG 任务调用（单写者）**；每 60s 打 `[SD] recs=N`
- **常驻自检**：金丝雀（STG 联网后写读一条缓存记录并消费，`[DL] canary online: OK`）+ DL_Append 写后回读探针（故障时打 hex+SR1，每上电限 2 次）——排查"静默写失败"（劣化网线注噪案，踩坑 #42）
- **验收**：SPL 四步（写入节奏/拔卡降级/插回恢复/断网并行）+ HAL 全绿；坏网线连环案（补传全灭三天）定案元凶=网线劣化，换线即愈
