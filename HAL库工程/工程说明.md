# HAL 库工程说明

> 生成日期：2026-10-02 ｜ 芯片：STM32F407VGT6 ｜ 库：STM32CubeF4 HAL（FW_F4 V1.28.3）
> 与 `标准库基础工程`（SPL 版）功能完全一致：Modbus RTU 采集 → W5500 MQTT 上云 → LCD 仪表盘
> 已通过命令行编译验证：0 Error / 0 Warning，且已上板验证全部功能正常

## 一、工程结构

```
HAL库工程/
├── Core/           CubeMX 生成层（main.c/gpio/spi/usart/rtc + it.c + hal_msp + hal_conf）
│   └── Inc/Src     main.c 内为阶段7仪表盘应用（含所有健壮性逻辑）
├── Drivers/        ST 官方库（STM32F4xx_HAL_Driver + CMSIS，只保留 F407 相关部分）
├── Hardware/       板级驱动（lcd_spi_154[ST7789 寄存器级]/delay/usart_app/modbus/w5500_bsp/mqtt）
├── Ethernet/       WIZnet ioLibrary（socket/wizchip_conf/W5500/DNS，硬件TCP/IP协议栈）
├── MDK-ARM/        Keil 工程（RTOS的多功能工业网关.uvprojx + startup_stm32f407xx.s）
└── RTOS的多功能工业网关.ioc   CubeMX 工程文件（外设/引脚/时钟全部在此配置）
```

## 二、与 SPL 版的差异

| 项 | SPL 版 | HAL 版 |
|---|---|---|
| 库 | StdPeriph V1.8.0 | HAL V1.28.3（CubeMX 6.15 生成） |
| 工程创建 | 手工搭建 | CubeMX 图形化 + MDK-ARM 工具链 |

## 三、CubeMX 重新生成须知（重要）

自定义代码全部写在 `/* USER CODE BEGIN/END */` 区内，重新生成不丢失。但以下三处**手工修改在生成区外面，重新生成会被覆盖，需要重打**：

1. `Core/Src/main.c` `SystemClock_Config()`：LSE 起振失败时降级 LSI 的回退逻辑（否则无 RTC 电池时整板卡死在 Error_Handler）
2. `Core/Src/rtc.c`：LSE 就绪等待 + 非致命初始化
3. `Core/Src/gpio.c`：LCD_DC/BL 引脚速度为 VERY_HIGH（DC 在 SPI 字节间翻转，低速档摆率不够）——此设置本身在 .ioc 里，只是注释会丢

**另外：不要在 CubeMX 图形界面里改外设配置/引脚**（SPI1/SPI3/USART1/USART2 及各 GPIO），Hardware 驱动是按当前配置写的。

## 四、编译验证

- 环境：Keil MDK AC5（V5.06u7）+ MicroLIB（必须，否则全量 C 库走半主机 BKPT，脱机即 HardFault）
- 命令行：`UV4.exe -r -j0 -o build_log.txt RTOS的多功能工业网关.uvprojx`
- 退出码 0 = 0 Error / 0 Warning

## 五、FreeRTOS 多任务版（2026-10-02，已上板验证）

- 内核 FreeRTOS V11.3.0（`FreeRTOS/`，7 文件：tasks/list/queue/event_groups/stream_buffer/port[RVDS ARM_CM4F]/heap_4）
- `Core/Inc/FreeRTOSConfig.h`：168MHz/1kHz tick/48KB heap_4/栈溢出检测2。**切勿定义 configSYSTICK_CLOCK_HZ**（会触发 port.c 外部时钟分支，tick 慢 8 倍，实测 MQTT 被服务器踢线）
- `Core/Src/app.c`：4 任务（WDG prio4 看门狗+心跳巡检 / COL prio3 Modbus 2s / NET prio3 在位+自愈+链路防抖+MQTT / DSP prio2 LCD 100ms 局部刷新），共享状态互斥锁保护
- **HAL 时基链式方案**：it.c 的 SysTick_Handler = HAL_IncTick() + (调度器已启动时) xPortSysTickHandler()，HAL_GetTick/HAL_Delay 全程可用，无需迁 TIM6/7
- `Hardware/delay.c`：RTOS 垫片（调度器前忙等/后 vTaskDelay），供 SPL/HAL 两工程共用同一套驱动
- ⚠️ **CubeMX 重新生成 it.c 会恢复 SVC/PendSV/SysTick 处理函数 → 与 port 重复定义（L6200E），届时删除生成版 SVC_Handler/PendSV_Handler 两个函数**（SysTick 的链式调用在 USER CODE 区，安全）

## 五、已验证功能（上板）

- LCD：ST7789 240×240 仪表盘（Link/MQTT/Temp/Hum/IP/PUB），固定坐标局部刷新
- Modbus RTU 主站：2 秒轮询温湿度（×10 补码），失败保持上次显示
- MQTT 3.1.1：broker.emqx.io:1883，5 秒发布 JSON，断网自动重连
- 健壮性：W5500 在位检测（版本寄存器 5 次防抖）、配置自愈（3 次防抖）、链路防抖（3 次）、全链路超时
- 故障指示：初始化失败/异常时 PC0 LED 快闪（与 2 秒心跳灯节奏区分）
