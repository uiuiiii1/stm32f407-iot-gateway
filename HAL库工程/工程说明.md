## 一、与标准库的差异（实现方式，功能一致）
- **延时**：HAL `delay.c` 调度器前用 `HAL_GetTick`（依赖 SysTick 中断）→ 必须 `__enable_irq()`（`Core\Src\main.c` USER CODE 区）+ `VECT_TAB_OFFSET=0x8000`（`system_stm32f4xx.c`）。标准库是 NOP 忙等，不需要（见踩坑 #38）。
- **开机签名**：HAL 打 `LCD: 0x29 ...`，标准库没有——多固件共板先核对签名。
- **.ioc**：CubeMX 工程，勿在图形界面改外设/引脚；自定义代码放 USER CODE 区；重生成会恢复 it.c 的 SVC/PendSV/SysTick 空函数（与 FreeRTOS port 冲突 L6200E），届时删生成版。

## 二、已含功能（与标准库对齐）
AT24C64 软I2C + 双槽书签 / datalog 断网缓存+补传（AT24C64 书签、30s 限流、`DL_BookmarkCommit`）/ SNTP / MQTT 订阅+下行 / OTA 下载器+确认+NotifyAlive / 应用搬家 0x08008000 / 共享 bootloader（A2 计数 + A3 Slot B 回滚）。
